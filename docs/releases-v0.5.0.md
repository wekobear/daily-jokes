# v0.5.0 · 首次用途选择与跨工具接续

日期：2026-09-13。版本规则为年度序号.功能版本.小更新；本次是 2026 年的功能更新。此前本地 v0.4.0 扩容内容一并发布，历史公开 v1.x 标签不改写；数字顺序不代表本次退回旧代码。

## 下载前看清楚，首次调用再选择

README 和新手教程在安装前展示两条路线，共用一个完整安装包：

- A：只看每日笑话，默认 10 个短篇加 1 篇原创脱口秀；可随时点播，需要定时推送再设置。
- B：把笑话做成内容，选最佳短篇，文字生成图片、图片生成视频，本地保存等用户自己上传。

首次调用且用途未知时只问一题；用户已经明确要文字、图片或视频就直接按范围执行。下载文件不弹窗，安装不等于授权生成或扣费。阅读不要求配置视频 API 或安装媒体依赖；定时获取与用途选择分开，不虚构订阅成功。

## 随时换路线，也能换工具

支持今天只看、以后默认阅读、指定条目转图文或视频。复用已有合格内容，保留付费任务状态；切换不等于取消订单或退款。

新增接续规则和 handoff.md 模板，列出所选产物、完成阶段和下一步。可在其他 Agent 或生产力工具读取，实际执行依赖目标能力；原任务仅经私有状态续跑，密钥单独配置，不把私有运行资料打进分享包。订阅不会随文件自动迁移。
