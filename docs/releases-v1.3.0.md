# v1.3.0 · 通用内容生产、新手教程与视频案例

这次将 jokes 整理为可复刻的内容生产 Skill：收集候选、分析笑点、选出当日最佳，生成图文与独立分镜，再由视频服务生成镜头，下载并合成，最后保存本地等待用户手动上传。

## 新增内容

- 供应商通用流程与替换约定。MiniMax 是随包已实现的参考适配，不再把整个方法绑定到单一视频 API；其他供应商仍需相应适配和真实验证。
- 面向新手的完整教程：安装、看案例、先做图文、运行环境、私有密钥、预算、断点续跑和查找成片。
- 当日最佳选稿的比较维度、权重与记录模板。
- 三类实际案例：雨伞静音／配音预演、十五秒本地配音图文视频、真实四秒 H3 动作试片。附图片、文案、提示词和视频。
- 使用 Archify 生成的通用流程 HTML 与静态预览，并保留项目致谢和许可证。

## 可靠性与边界

支持原创和用户供稿的诚实来源标记，不要求虚构 URL；本地配音修正了外部文本被误识别为命令选项的问题。分享包使用明确清单，排除密钥、Cookie、私人运行状态和本机路径。

流程默认以本地待上传结束，不包含任何社交平台上传器。四秒 H3 样例只是单镜验证，不代表完整三镜 H3 成片。视频服务的新适配不因文档通用化自动变成已实现。

本轮不新增付费生成，现有代码测试与新增来源交接测试覆盖共 44 项通过。流程图分别通过 9 项确定性校验和四种桌面尺寸浏览器检查；案例视频在发布前做本地解码检查。
