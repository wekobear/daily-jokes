# 从零开始：只看笑话，或把笑话做成作品

你不需要先学会写程序，也不一定要做视频。这个 Skill 有两种用法：让 Agent 每次精选笑话给你看；或者继续选稿、生成图片分镜，再调用你选择的视频服务制作成片。只想看笑话，就走 A 路线；想做作品，再走 B 路线。

## 下载前先选用途

- **A：只看每日笑话。** 随时点播，不配置视频密钥；有需要再设置定时推送。
- **B：制作图文和视频。** 文字 → 图片分镜 → 视频 → 本地保存，由你最后上传；也可以停在图文。

两条路线共用一个安装包，随时可切换。下面先安装，再按所选路线阅读，不必把所有步骤都做一遍。

先记住三个区别：Skill 是流程说明和工具包，不是一个自带余额的视频网站；图片分镜不是人物会动的视频；保存到本地，也不等于已经发到了某个平台。

## 先看看能做出什么

打开 [案例展示](../examples/README.md)，先看三个不同阶段：

- 雨伞误会：图文分镜，以及静音／中文配音预演。
- 因为这儿亮：十五秒本地配音图文视频，带字幕和轻微镜头推进。
- 路灯下的老人：真实第三方 API 生成的四秒动作试片。

这些文件已经做好，直接播放不需要 API Key，也不会产生视频生成费用。前两类不能冒充第三方动作视频；最后一条只有结尾镜头，不是完整十五秒故事。案例原始提示词、来源和图片均随包提供，模型再次生成的结果可能不同。

## 第一步：安装完整 Skill

从 [v0.5.0 发布页](https://github.com/wekobear/daily-jokes/releases/tag/v0.5.0)下载 `jokes.zip`，解压得到 `jokes/` 文件夹。不要只拿出 `SKILL.md`，其余参考文件、脚本和案例都要留在原来的相对位置。

把整个文件夹交给支持 Agent Skill 的工具，按该工具的安装入口添加。若不知道安装目录，可以直接对 Agent 说：

```text
请把我提供的 jokes 文件夹安装为当前工具可用的 Skill。
保留完整目录，并检查是否可以调用。先不要生成内容或调用付费服务。
```

在 Codex 中，可以通过技能选择器选中 jokes，或输入 `$jokes`。其他工具按自身入口调用；复制斜杠命令不一定会自动注册技能。

## 首次调用：回答一题即可

输入 `$jokes 开始使用`。如果还不知道你的用途，Agent 会问“只看每日笑话，还是制作图文和视频？”回复 A／B，或直接说自己的需求即可；不需要先填题材、时间、密钥等一整张问卷。

下载或安装本身不会弹窗、生成内容或扣费。你若直接说“只看今天的笑话”或“把这则做成视频”，已经表达了选择，Agent 应直接执行。明确“先用默认”会按本次阅读处理；选择不会自动变成定时订阅或永久设置。

## 路线 A：只看每日笑话

最简单的一句是：

```text
$jokes 只看今天的笑话，默认 10 个短篇加 1 篇脱口秀。
不要图片，不做视频。
```

你也可以把想看的题材说清楚：

```text
$jokes 来今天的一组，10 个短篇加 1 篇脱口秀长稿。
包含原神、钓鱼等圈层，默认 6 则短笑话、2 段相声、
1 则苏联政治笑话、1 段新写的英式官僚讽刺对话。
相声计入十个之内，长稿另外写，今天写钓鱼主题。
不出现调侃中国或中国领导人的政治笑话，也不使用代称或影射。
读取 A-Joke 及其他可核验来源，不复制经典作品的大段台词。
先只要文字，不生成图片或视频。
```

你应收到编号 1—10 的短篇与单独一篇长稿。相声有多轮台词，但整段只算一个。可以改成“十个都讲原神”“相声只留一段”“今天不要政治题材”或“只要五则，不要长稿”。未指定受众时尽量让普通观众听得懂；给圈内人看可直接说。

A-Joke 是历史候选库，Agent 还要实际读内容、核对出处、筛掉重复包袱。它不包含所有新圈层素材，更不证明某梗现在流行。需要自己取候选时按[素材说明](../references/joke-sources-and-circles.md)执行导入命令；默认一次取 30 个候选再精选，而不是全部发布。

参考[钓鱼脱口秀长稿](../examples/daily/standup-fishing.md)与[相声／讽刺短段](../examples/daily/short-formats.md)，它们是新写的虚构教学稿，不是用户经历或经典台词。题材与表演形式的区别见[写作说明](../references/performance-formats.md)。

收到文字后，阅读路线就完成了。以后想看再说“再来一组”，或者“今天只要五则钓鱼笑话”。不用安装 Python、FFmpeg，不用购买视频服务。当前 Agent 的文字或搜索额度按你自己的账号规则使用；并不意味着所有模型服务免费。

### 想定时收到，而不是每次点播？

可以说：

```text
$jokes 如果当前工具支持自动生成与送达，帮我设置每天早上 8 点推送文字笑话。
时区 Asia/Shanghai，送到当前对话。只要文字，不制作媒体。
先检查有没有已有订阅，避免重复创建。
```

把时间、时区和送达位置换成你需要的。Agent 只有在真实工具创建或更新成功后，才能告诉你“订阅已设置”。如果当前工具不支持，就继续手动点播；装好 Skill、保存时间偏好或创建日历提醒，都不等于会每天生成并推送笑话。

## 路线 B：把笑话做成图文和视频

如果从第一天就选 B，Agent 会先按主文件完成文字稿，再选最佳一则继续；视频预算和密钥到需要时才处理。如果已经在 A 路线拿到文字，直接复用，不需要重新生成整组。

### 第二步：为其中最佳一则做图文

把下面这段发给 Agent：

```text
$jokes 从刚才十个短篇里选最适合短视频的一则，面向普通观众。
说明简短选稿理由，保住必要铺垫与包袱。
生成可阅读的图文稿和三个独立竖屏分镜，先不调用视频 API。
请把来源、文案和图片保存到本次内容目录。
```

Agent 会读取候选的真实内容，筛掉逻辑不通、包袱重复或需要解释的笑话，再比较好笑程度、易懂程度和可视化难度。“最佳”只指本次候选中的编辑选择，不是全网排名。

你应该看到一份图文稿、实际图片，以及候选分析。如果只拿到提示词，还不算图文制作完成。搜索、生图使用当前工具实际具备的服务，其额度或费用按你的账号规则计算；“不调用视频 API”不代表所有外部服务免费。

### 第三步：选视频路线

| 你要的效果 | 路线 | 需要什么 |
| --- | --- | --- |
| 先检查故事节奏，图片配音即可 | 本地配音图文视频 | macOS 中文音色、Python、FFmpeg；不需要视频 Key |
| 人物有动作、表情变化，可能有原生声音 | 第三方视频 API | 该服务的账号、视频能力、密钥和本次预算 |
| 已有其他视频供应商 | 沿用同一生产流程，替换服务接入层 | Agent 先按官方文档适配，不能只改域名 |

本版本附带可运行的 MiniMax 参考脚本。流程本身不绑定 MiniMax；其他服务的请求字段、任务状态、时长和音频能力不一定相同。更换方法见 [视频服务替换说明](../references/video-provider-contract.md)。

### 第四步：让 Agent 检查运行环境

可以直接说：

```text
请检查这个 Skill 的运行环境，按文档补齐必要依赖。
检查 Python、Pillow、FFmpeg、ffprobe 和中文字体。
不要输出我的密钥，不要提交视频生成任务。
```

愿意自己操作的用户，在 `jokes/` 根目录运行：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
source .venv/bin/activate
python3 scripts/pipeline.py doctor
```

上面只安装 Python 依赖，不会安装 FFmpeg、字体或系统音色。缺什么就让 Agent 根据当前系统补齐，不把 `doctor` 的输出当作全部环境已经通过。附带脚本支持 macOS/Linux；Windows 原生环境尚未验证。本地系统配音目前是 macOS 路线。

### 第五步：自行配置视频密钥

以附带 MiniMax 实现为例，先在服务商平台获得可用于视频的按量 API Key 和余额。文字模型订阅不一定包含视频额度。

在本地文件管理器中复制 `.env.example`，副本命名为 `.env`，用本地编辑器在 `MINIMAX_API_KEY=` 后填写自己的值。文件需要保留纯文本格式，不要变成 `.env.txt`。也可以使用仓库外的私有环境文件，并告诉 Agent 文件位置。

不要把 Key 发到聊天里、截图里或提交到 GitHub；Agent 只需要知道文件位置。`.env` 已被忽略，分享时仍请使用项目的打包脚本，而不是压缩整个目录。换用其他供应商时，使用其适配器定义的密钥字段，不假定 `MINIMAX_API_KEY` 通用。

### 第六步：先估算，再生成

第一次可以复用案例首帧做低成本试片：

```text
$jokes 使用 examples/h3-trial 的故事输入和首帧，
通过已附带的 MiniMax 适配器生成一镜四秒试片。
密钥从本地 .env 读取，先核对当前价格；本次视频预算 2 元。
超过预算就停在估算，不增加镜头，不自动重生成，结果保存本地。
```

“2 元”是按案例当时费率设置的预算，不保证以后永远够用。试片验证的是角色动作和 API 接入；完整故事要重新按总镜头时长估算，不能把试片费用漏掉。

要制作刚才的完整图文故事，可以说：

```text
$jokes 把刚才的图文分镜继续做成完整视频，保住铺垫和结尾包袱。
使用已经配置好的视频服务；先给出总费用估算。
本次视频 API 总预算 8 元，包含本次已经生成的试片和重试费用。
预算内完成生成、下载、合成和检查，保存本地，不上传、不发布。
```

生成通常是异步任务：先拿到任务标识，等待服务处理，再下载。看到“处理中”不必重新点生成。需要接着跑时说“检查上次状态，继续查询原任务，不重复提交”。如果提交结果不明，先核实已有任务，避免重复消费。

### 第七步：找到成片并检查

每次运行会单独保存到 `runs/` 下的一个内容目录。图文稿通常是 `graphic-story.md`；MiniMax 参考流程的成片在 `output/final.mp4`，同目录有字幕和封面；本地配音路线的成片在 `local-video/local_video.mp4`。

播放时检查：人物有没有变、道具是否正确、字幕是否遮挡、台词是否说全、最后一句是否被切断。文件能播放和有音轨，并不能证明台词正确。Agent 无法实际听音时，应标记待你检查，而不是虚构验收通过。

实际检查通过后，参考流程可以生成 `upload-package.zip`，包含视频、封面、字幕、发布文案和待上传清单。把它交给自己选用的视频平台，手动上传。没有视频号或其他平台账号也不影响在本地制作内容。

## 随时切换路线或换工具

不需要卸载重装。你可以直接说：

```text
$jokes 今天只看笑话，不再做图片和视频，保留已经生成的文件。
$jokes 把刚才第 2 则做成图片，只转换这一则。
$jokes 以后默认只看文字；如有相关自动媒体任务，检查并停止后续媒体生成。
```

“今天”只改这一次；“以后”仅在允许的私有位置实际保存成功后才会跨会话生效。已提交的视频任务不会因切换自动退款；Agent 应保留状态，不重复下单。已有订阅不会因为你临时换路线就默默取消。

想换到另一款 Agent 或生产力工具时，可以说：

```text
$jokes 我要换工具继续。请在当前内容目录生成 handoff.md，
列明我的用途、已完成阶段、下一步，以及需要带走的文字、图片和视频。
保留内容禁区，不加入密钥、私人经历、登录资料或真实任务标识。
如果已有付费任务，说明如何在我的私有目录核验原状态，不重新提交。
先整理交接材料，不对外发送。
```

将完整 `jokes/` 和你选择的内容文件交给新工具，再说“读取 Skill 和 handoff.md，从已完成阶段继续”。不支持安装 Skill 的工具也可阅读这些说明，但生图、执行脚本和视频生成仍取决于它的真实能力。只是想看文字，复制所选笑话就够了。

公开交接材料不带 `state.json`；确需接续付费任务时，让新工具读取你指定的同一私有工作目录，或由你通过私有方式迁移必要状态，密钥在新环境单独配置。跨工具不代表凭据、定时订阅或预算授权自动迁移。详见[接续规则](../references/first-use-and-switching.md)与[交接模板](../assets/handoff-template.md)。

## 常见问题

**没有视频 Key，能做什么？** 可以看随包案例、生成文案和图片；具备本地环境时还可以做配音图文视频。不能把它称为第三方动作视频。

**换视频 API 要重写全部流程吗？** 不需要。选稿、角色、分镜、字幕和最后交付沿用；更换服务的参数、凭据、计费、任务查询和下载适配。新适配器需要真实验证后才算跑通。

**为什么图片好看，视频还是不稳定？** 图片是首帧，不保证模型在运动时保持全部细节。先减少角色、场景切换和复杂道具动作，保证一镜只承担一个节拍，不无限付费重抽。

**为什么不能重复初始化目录？** 旧目录包含任务状态和已经付费的镜头。继续任务用原目录；换故事或修改已提交内容用新版本目录，同时保留旧费用记录。

**安装后会每天自动跑吗？** 不会。需要另外明确运行时间、时区、保存位置和每次预算，并使用宿主实际提供的定时能力。

准备分享时，分享 `jokes.zip` 或明确选择的成片，不分享 `.env`、`state.json`、整个 `runs/` 或浏览器登录资料。更多细节见 [完整生产流程](../references/daily-production.md)和 [案例展示](../examples/README.md)。
