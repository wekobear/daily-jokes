# 首次使用、分路执行和换工具

这是 Agent 的执行约定，不是下载器、独立路由程序或跨工具同步服务。入口问句见 [SKILL.md](../SKILL.md)，新手可直接看[操作教程](../docs/getting-started.md)。

## 1. 只问还不知道的用途

先读当前需求和可合法读取的已确认选择。首次裸调用、模糊的“来一组／开始使用”且没有已知用途时，问阅读或生产，一题即可；等待实际回答。下载页的介绍不是已选答案，安装完成也不是生产授权。

- 明确“看笑话／文字／只要十则”：已经选择阅读，直接执行指定范围。
- 明确“文生图／漫画／图生视频／继续上次视频”：已经选择相应生产阶段，不重复用途问询，不自动补做整组或整条流程。
- 明确“先用默认／别问”：仅本次阅读；取消或未答时不启动任一路线，不循环催问。
- 原请求要生成，回答 A／B 后保留并继续该请求；仅设置用途时不附赠内容。
- 后台任务读取已确认配置，不在每次触发时提问。不猜测缺失的必要订阅配置。

## 2. 按路线加载和执行

| 用途 | 要做什么 | 停在哪里 |
| --- | --- | --- |
| `reading` 阅读 | 按主文件收集、查重和筛选；默认交付 10 个短篇 + 1 篇独立长稿，数量和题材可覆盖 | 展示文字即完成；不为了视频选最佳、装依赖、问密钥或预算 |
| `production` 生产 | 按[每日生产](daily-production.md)完成文字，选最佳短篇，生成图文和独立图片，再接[视频流程](video-workflow.md) | 完整请求止于本地待上传；只要图文则止于图文，只有提示词不称已生图 |

阅读路线只需要当前 Agent 的文字能力；收集网络素材时用其实际搜索工具，没有则如实说明并在用户可接受范围内使用已有素材或原创。运行 A-Joke 导入脚本才需要 Python；不要求只看笑话的人安装媒体环境。选择生产不等于已有视频预算或账号：按阶段检查能力，缺视频 Key 不阻塞文字与图片；缺生图能力则保留分镜文本并说明未完成图片。

用途 `workflow_mode` 与获取方式 `mode=manual/scheduled` 分开。选择“只看每日笑话”默认当次展示，不自动订阅。明确要定时后，按[状态说明](onboarding-and-state.md)补足真实时间、时区与目标，查询既有任务并创建或更新，核验成功才称订阅成立；不能把日历提醒冒充自动生成和推送。只想看的人可以一直留在阅读路线，无需升级成创作者。

## 3. 随时切换，保留已做好的内容

| 用户说 | 执行 |
| --- | --- |
| “今天只看笑话” | 本次阅读，暂时覆盖旧的制作偏好，不改以后配置或既有订阅 |
| “以后只看，不做视频” | 在获准的私有配置中更新默认用途；无持久化能力则明确仅当前会话生效。若已有自动媒体任务，按这项停止媒体的请求查询并更新，核验实际结果，不直接另建订阅 |
| “把刚才第 2 则做成图片／视频” | 直接复用指定条目，进入请求阶段；不重新生成 10+1，不把本次转换自动设为永久偏好 |
| “以后走完整生产路线” | 更新明确允许保存的用途；涉及现有定时任务先核对媒体能力、每次预算和实际任务配置，未补齐前不把原文字任务改成自动扣费任务 |
| “换个 Agent 工具接着做” | 先整理下面的接续材料，在新工具检查能力和文件，再从已完成阶段往后做 |

中途切回阅读，停止后续新媒体提交；已经提交的付费任务不因切换就取消或退款。保留原任务状态，报告仍在处理的项；必要时查询原任务，避免重复计费。切换不删除旧图片、视频或文章，也不默默撤销现有订阅。

仅本次切换只在当前上下文使用。用户明确要求保存以后偏好且有允许的私有位置时，才实际写入并回读。不要改公共 SKILL.md 来记录用户选择。可使用 `workflow_mode=reading/production`；旧配置无此字段时依据当前明确意图选择，模糊首次调用则提问，不凭旧的 `mode=manual` 推定用途。

## 4. 把进度交给另一款工具

用户提出换工具时，由当前 Agent 按[交接模板](../assets/handoff-template.md)在用户允许的内容目录生成 `handoff.md`。若不能写文件，交付可复制的交接正文，并准确列出仍需用户提供的文件。只列实际存在且需要的产物，用相对路径，不虚构文件或已完成状态。

1. **带走规则。** 复制完整 `jokes/` 安装包至支持 Skill 的新工具；不支持安装的工具可读取 SKILL.md 与相关参考文档，但不能声称已注册命令或具有执行能力。
2. **带走所选材料。** 阅读可只带题材、禁区和用户选中的文字；制作带对应来源、故事、选稿、图片、已有视频和交接说明。默认不带私人经历、完整聊天、账号或候选全文库。固定内容禁区在交接中保留。
3. **分开处理运行状态。** `state.json`、真实任务标识和签名下载地址不进入公开交接包。若要接续原付费任务，可在用户明确指定的同一私有工作目录读取原状态；跨设备时只经用户认可的私有方式迁移必要状态和产物，按新路径核对文件。密钥在目标环境单独配置，不写进 handoff.md。未拿到原状态或未查清原任务时停在待核验，不新建同一付费任务。
4. **目标工具验收。** 先核对收到的文件、用途、指定条目、完成阶段、待办、内容禁区及本次有效预算。只读检查当前工具需要的搜索／生图／执行／视频能力；缺什么具体说明，不承诺跨工具自动兼容或原密钥已迁移。
5. **从断点继续。** 有合格图片就从视频阶段继续，有成片就检查和交付；不因换工具重复选稿、生图或付款。新工具无法执行时仍可只看文字，或交付剩余提示词和待办给用户选择的工具。

已有定时订阅不会随文件自动搬家。只换制作工具不改订阅；明确迁移订阅时先核验原任务，协调停用与新任务创建，避免两边重复推送，任何一步未完成须说明。普通交接不对外上传材料，不公开发布。
