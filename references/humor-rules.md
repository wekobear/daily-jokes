# 幽默规则

用于候选生成、来源筛选、主导结构判定及最后精简。状态与授权见 [首次设置与状态](onboarding-and-state.md)。

## 来源和原创判定

- 先按用户题材与具体内容检索，可参考公版故事、可合规使用的经典段子及可靠整理；不只搜“爆笑笑话大全”。网络内容是否好笑需实际阅读，搜索排名不证明质量。
- 拟采用的内容要有可核验的来源及足够上下文。标题、断裂摘要、无法打开的页面不等于读过完整笑话；能直接读到完整相关内容的工具结果可以核验。
- 来源实际支持所采用包袱才引用。转引页标作实际读到的整理／转载来源，不能冒称原作者；没有证据不赋予“经典”“广为流传”或作者、年代等身份。
- 遵守宿主的单来源引用、改写与版权限制；不长段照搬现代作者作品，不用逐句换词规避限制。无法合规使用时舍弃该候选。简洁改编仍属于网络类。
- 原创要求核心包袱独立构思。更换经典段子的名字、行业、产品或让用户担任主角，仍是网络改编；自嘲素材来自用户，不自动使包袱成为原创。未检索到同梗不证明全球首创，不作此保证。
- 翻译应自然成立，舍弃目标语言中失效的谐音或依赖陌生文化的包袱，不靠解释补救。
- 近期新闻、真人、真实公司相关的必要事实先核实。夸张、拟人和虚构场景应自然显露为假设，不包装成真实发言／事件，不编造有害事实。
- 网络类条目末尾用宿主要求的最短来源引用，指向实际读取页面；原创不伪造包袱来源；依赖已核验热梗背景的原创可按下节附背景来源。多条使用同一来源时，合计遵守该来源的引用限制。

## 近期流行梗

热梗是可选的素材线索，不是笑话质量、原创身份或第十九种主导结构。未排除时默认择优纳入 1—2 条，不凑配额；用户可要求不用、少用、多用、全部使用，或指定平台／圈层。偏好未填不阻塞已完成的首次配置，不额外增加必答问卷。全热梗仍需五个不同梗、五种主导机制及正常混合来源；不足时简短说明实际缺口，不以旧梗或同梗变体冒充达标。

**核验“近期”。** 以本次实际日期为基准，结合允许题材、目标语言及用户指定平台检索，优先查近 7 天；证据不足可扩至近 30 天，并在内部保留实际时间范围，不能称其为本周新梗。没有可靠当前日期时不宣称最新。核对内容发布时间、所述事件时间与最近传播时间；刚发布的盘点文章、搜索排序、旧页更新时间都不能单独证明梗刚出现或正在流行。旧梗有近期传播证据时可作为翻红梗，不能说新诞生。不要把任何固定梗表写进共享 Skill 并永久视为最新。

**核验传播与含义。** 读取可访问的原帖／原视频文字内容或足够上下文，确认梗的用法、适用场景；再找独立的近期实际使用，或有明确时间范围的平台热度证据，支撑其在相应圈层传播。多家复制同一盘点不算独立传播，单帖发得新不等于流行；单个平台的证据不支持“全网爆火”。能确认近期用法但找不到最初出处时，引用实际读到的传播来源，不虚构起源或发明者。用户指定的梗可以创作，热度未经核验时仅按指定素材使用。

**把梗变成笑话。** 拿掉流行词后，仍要能指出清楚的冲突、误导或揭底；不能只是把热词贴在已有笑话结尾。依赖梗本身语义也可以成立，但必要信息要自然融入铺垫，让不了解原视频的读者也能理解；需要长篇科普、读评论区才懂或出稿后补解释的，舍弃。真实事件背景先核实；沿用用户禁区、尺度和来源规则，热门不构成例外。

**分类、引用与查重。** 借用梗原有的反差、固定问答或揭底，算网络改编；只是以流行现象为背景、核心包袱另行构思，才可计原创。后一种也在条目末尾附必要的背景来源，引用不表示包袱来自该页面。对同组及可读历史同时比较梗的别名／变体和核心包袱；换平台、谐音写法或主角不算新梗。跨日即使包袱不同，也优先避免围绕同一个热梗连续出稿。核验依据仅用于本次判断；历史字段保存遵循既有权限和期限，不默认建立永久热梗库。

**核验不足。** 少量定向检索及一次时间范围扩展后仍证据不足，就停止追查该候选。常规混合组可改选已核验的普通网络笑话及原创，不需要声称整体搜索失败；用户明确要求最新热梗而无法满足时，用一句话说明“未能核验近期热度”等实际限制，再给可满足的普通组合，不称其为最新热梗。用户明确只接受热梗时，缺少合格素材就报告缺口，不擅自用普通笑话替代。无联网或禁止联网依入口的准确原因降级；记忆和旧缓存不能单独证明当前热度。

## 主导喜剧结构

只按“包袱主要靠什么成立”分类。先在内部用一句话概括核心机制，再选最贴切的一个结构；拿掉该机制后仍成立的手法，多半只是辅助技巧。下表给出稳定的内部 ID，供非敏感历史统计使用，不展示给听众。

| ID／结构 | 包袱的主要支点 | 与相近结构的边界 |
| --- | --- | --- |
| misdirection／误导反转 | 铺垫让人形成合理解释，结尾用另一事实重新解释前文 | 仅有意外不足；若依赖特定词义、形式规则或逻辑倒置，优先归入对应具体机制 |
| rule_of_three／三段式 | 前两拍建立清楚的模式，第三拍偏离模式 | 必须依赖两次建立加一次破格；普通三句对话不算 |
| ambiguity／双关与歧义重释 | 同一词、音或句法有两种解读，揭底切换解读 | 若关键是把比喻／惯用表达当成实体动作，归字面理解 |
| literalism／字面理解 | 将比喻、惯用语或社交隐含意思当成字面要求执行 | 普通同音或多义词切换归歧义重释；不只因角色“很认真”就归此类 |
| logical_inversion／逻辑反转 | 倒置因果、目标与手段、条件或评价标准，并贯彻错误逻辑 | 有明确推理倒置才用；仅揭示隐藏事实归误导反转 |
| escalation／递进升级 | 同一困境或规则连续加强，最后推到极端 | 多步累积不可缺；单次比例失真归夸张 |
| exaggeration／夸张 | 通过数量、程度、速度或尺度明显失真显露反差 | 不要求连续升级；换成常态尺度就不成立 |
| understatement／轻描淡写 | 明显巨大后果与极其克制的措辞不相称 | 笑点在说法过轻；实际结局变得琐碎归反高潮 |
| observation／生活观察 | 精准指出熟悉而未被点破的小规律、矛盾或具体细节 | 不是一般抱怨或生活感悟；依赖讽刺对象的反规范行为时优先讽刺 |
| analogy／类比 | 将两个相距很远的领域以具体对应关系接起来 | 去掉跨领域对应就失效；装饰性的比喻不算主导 |
| callback／回调 | 后段让本笑话已建立的细节带着新意义重现 | 先建立后回收，依赖前文关联；跨日旧梗须在本条补足必要信息，独立可懂 |
| repetition_variation／重复变奏 | 同一短句、动作或节拍的重复，在变化语境中产生新意义 | 笑点依赖反复比较；恰是第三拍破格则归三段式，只是程度增加则归升级 |
| anti_joke／反笑话 | 先借用笑话的套路诱发“会有包袱”的预期，再用刻意普通的实答拆掉套路 | 普通没包袱的句子不算；必须能感知对笑话惯例的拆解 |
| anticlimax／铺垫后的反高潮 | 叙事将某件事的重要性或悬念抬高，结果落在琐碎小事 | 依赖叙事落差；无需先识别笑话形式，区别于反笑话 |
| absurdity／荒诞与超现实 | 不可能的前提被角色当成日常，并有一致的局部逻辑 | 不是随机拼接；若只是常态事实夸大而无新世界规则，归夸张 |
| satire_parody／讽刺与戏仿 | 揭露观念、制度、话术的自我矛盾，或模仿可识别样式让其失真 | 需要可识别的讽刺对象或样式；名著人物客串不自动算戏仿 |
| character_behavior／角色行为喜剧 | 角色稳定的小执念或性格驱使其作出令人发笑的选择 | 笑点依赖行动中的性格，人物姓名／职业标签本身无效 |
| self_reference／自指幽默 | 笑话谈及并影响自己的讲述、措辞或构造 | 第一人称、自嘲、提到 AI 不自动成为自指 |

一句话、问答、对话、小故事是呈现形式；日常、职场、文学是题材；自嘲是素材使用方式，都不是新增结构。不能用同一包袱的多个辅助技巧冒充本组的不同主导机制。无法明确区分两个候选时，视为重复并替换其中一个。

## 候选与重复检查

正常先形成多于 5 条的候选，再按质量选取。优先顺序是授权／安全／来源合规、本组五种真实不同机制及成立的包袱，再优化 7 天分布、网络与原创比例、题材和形式。混合来源仍是正常模式要求；只有入口定义的检索异常允许全原创。

内部对每条候选提取：题材、核心包袱、误导前提、揭底逻辑、主导机制、呈现形式、来源类别。对同组及可读 7 天历史作语义比较：

- 只换名字、职业、品牌、地点或时代，同一揭底仍能原封不动迁移的，视为同梗。
- 不只看文字相似度；检索改编和原创若撞核心机制与包袱，也要更换。
- 同一结构可包含不同包袱，但本组仍只用一次。不同结构标签不能洗掉相同核心包袱。
- 18 种结构每种至多 2 次只有 36 个名额；每天五条的七天窗口已经需要 35 个，追加点播或部分结构不合适时可能无法达到目标。每 7 天至多 2 次只是软目标，不伪造分类，不为了配额保留差笑话。
- 优先减少当前窗口已频繁出现的结构；以真实分类和质量决定超出软目标，不额外输出轮换分析。不虚报查重范围。
- 回调旧梗时必须有新的笑点，本条自行交代必要信息；不以“你还记得昨天那个吗”代替包袱。

## 避免换皮：比较关系，不只比较名词

把候选在内部抽象成“角色想达成什么 → 做了什么 → 听众预期 → 实际揭底 → 为什么前文因此被重释”。临时遮掉人名、名著、公司、职业和产品名称，检查包袱是否仍能原样迁移；这一步只处理当前已授权素材，不增加持久化权限。

区分三种相似，避免一刀切：

| 相似程度 | 判断 | 处理 |
| --- | --- | --- |
| 核心包袱复用 | 换了名词或多写几句，但关键行动、误导方式和最后揭底可互换 | 替换整条；不能只改口吻、品牌、时代或结构标签 |
| 同一母题饱和 | 都围绕“提效反而更忙”“买方法却不行动”“改稿不停”，但具体包袱可能不同 | 优先换一条为其他冲突与揭底；作为多样性问题处理，不机械宣称每条都是抄梗 |
| 仅题材相同 | 都写同类人物／物品，核心关系和揭底机制实际不同 | 可以保留，仍需满足本组机制不同；不因关键词相同误杀 |

重点留意这些容易耗尽变化的母题，它们是检查线索，不是对所有用户的永久禁区：

- 自动化提效最终变成人类审核、管理、催进度；不要只增加助手数量或更换组织背景。
- 要求局部修改却删掉功能、把责任推回请求者；换工具、变代码行数不产生新核心包袱。
- 买书、课程、收纳用品或效率工具后，行动仍未开始；更换商品不能替代新的揭底关系。
- 反复修改后退回初版，或用疲惫、玄学、缘分收尾；若只是在表达工作烦恼，应淘汰。
- 将名著或历史人物直接塞进开会、上线、甲方场景；人物须参与包袱成立，而不只是题材装饰。

可保留的写作方法是：让结尾的一项具体事实回头解释铺垫；让回答切换问题中真实存在的词义或计量维度；让自指笑话在自身文字形式里兑现矛盾；让角色行为产生能追溯的后果。这些是评审判断，不代表任何用户对历史中每条笑话的明确赞同。

两条各自有好包袱的故事，若都靠“此前解释错了，最后补一个隐藏事实”，仍可能同属误导反转，本组不能把它们算作两种结构。反过来，结构相同并不自动证明跨日复用了同一个包袱，要继续比较具体关系。

## 结尾的逻辑复核

- 反差要落在具体动作、可重释的信息或可感知的规律上；一句“忙累惨”“又得改”及行业黑话本身不等于笑话。
- 三段式不等于列出三个阶段。第三拍需要改变前两拍建立的预期，仅换成“第很多版”再叹气通常不足。
- 物理空间、数量、因果要能成立。物体叠高却声称承载面降低，若无铺垫支持视角变化，就是逻辑漏洞；不能靠笑点解析补回缺失条件。
- 不在最后突然发明处罚、资格取消或任意规定，只为了制造意外。荒诞需要先建立或可回溯的局部规则；反笑话需要可识别的笑话惯例，不以“就是无聊”作为豁免。
- 以死亡、受伤、羞辱为主要冲击的网络段子，不因出处有名就适配温和模式；照当前用户禁区和尺度重新筛选。

复盘用户指定历史时，分开记录明确反馈、可观察的重复模式和评审推断。读取旧答案不等于复核其中来源；历史原生引用 ID 不能直接搬到新会话冒充可核验链接。若想再次采用其网络素材，应找到并实际读取对应来源，不能复用旧答案的“经典／原创”自我标注。

## 自嘲的写法

素材授权与期限按状态文件处理。只调侃具体行为、小习惯、反差、判断失误或轻微尴尬；不评价人的人格、智力或自我价值。默认用第一人称，避免居高临下的“你就是”。

不主动以疾病、创伤、丧失、身体羞辱、严重财务困境或关系伤害为包袱；即使用户明确指定敏感经历，也要遵守其禁区和宿主安全规则。优先缩小到可轻松调侃的具体细节。

可夸张，但不把新增情节当作用户事实。用“我仿佛……”或“照这个趋势……”自然表达假设；不擅自引入工资、关系、单位等背景。默认去除实名、单位、精确位置、账号及可识别第三人细节，对本人授权不扩展为羞辱其亲友同事。

默认每组最多 1 条自嘲，计入原有五条；不好笑可不选。明确要求整组自嘲可提高比例，仍需五种主导机制与正常混合来源，自嘲改编仍按网络类归属。

## 出稿前

每条只保留理解所需的铺垫，把最有力的字词放在收尾，删掉解释、反复提示和普通抱怨。调换顺序使长短与形式有变化，不固定网络、原创、自嘲的位置。

“好笑”“自然”“冒犯是否无伤大雅”需要结合语境及用户反馈判断，结构和字数检查不能证明幽默质量。收到明确反馈再做适度更新，不以一次不喜欢推导永久且广泛的禁区。
