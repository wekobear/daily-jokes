# 公开素材与圈层选题

参考[多路研究与统筹筛选](../docs/research-v0.4.0.md)，含已读来源、候选取舍和未核验线索。这是带日期的教学记录，不是永久最新素材。

## A-Joke 候选源

感谢 [Licoy/A-Joke](https://github.com/Licoy/A-Joke) 的整理。2026-09-13 核查固定提交 `9d87e1c8f3fe9123c54fcc818e7fbd0255fd14a4`，有 131 份日刊 Markdown，日期范围为 2018-06-28 至 2018-11-05。这是文件数量，不是笑话总数，更不等于已审核可发布数量。

[许可证](https://github.com/Licoy/A-Joke/blob/9d87e1c8f3fe9123c54fcc818e7fbd0255fd14a4/LICENSE)为 MIT；[README](https://github.com/Licoy/A-Joke/blob/9d87e1c8f3fe9123c54fcc818e7fbd0255fd14a4/README.md)说明笑话收集于网络，并提供侵权反馈方式。因此将其作为历史候选库，不宣称每个段子都是公版或已获商业使用许可。保留实际整理来源，不能冒充原作者。

在 Skill 根目录执行，无需视频 Key、GitHub 登录或额外 Python 依赖：

```bash
python3 scripts/collect_jokes.py --date 2026-09-13 --count 30 --issues 4 --output runs/2026-09-13/candidates.json
```

换为实际日期及新输出路径。脚本读取固定提交的目录和最多 4 份日刊，解析标题、正文、日期、条目与精确来源链接，按日期确定抽样顺序，做标点／空白归一后的精确查重。同日期同参数的抽样相同，读取时间不同；同日加更由 Agent 换来源或对照历史替换，不能重复交付相同抽样。

默认返回最多 30 条未审候选，不是精选后的 10 个节目。缺量或日刊读取失败记录 `shortfall`／`failed_issues`，缺量返回退出码 2。Agent 保留已有候选，补充其他来源或原创，不无限重试。完整联网失败会报错，不写假成功文件；输出文件已存在则拒绝覆盖，续用时先读原文件。

Agent 逐条阅读、判断内容和使用条件、归类圈层、识别核心包袱、对可读历史做语义查重，再改编或舍弃。不能自动将 `circles: []`、`review_status: unreviewed` 改成已审核。脚本不执行上游 `run.py`，不读取密钥；候选存在被忽略的 `runs/`，不随安装包分发。添加其他库时沿用这些来源字段，先核验格式和使用条件。

## 开放圈层表

这张表是取材方向，不是现成段子或永久热梗清单。A-Joke 不提供所有圈层资料，不能用旧库存冒称后来的游戏素材或当前热点。

| 圈层 | 可观察场景 | 写作要求 |
| --- | --- | --- |
| 原神及其他游戏 | 配队、探索、收集、朋友联机、背包整理 | 规则查对应官方资料；版本、活动、概率先核验，不编更新，不把玩家身份当笑点 |
| 钓鱼佬 | 天没亮出门、带装备、选钓位、等待、收竿复盘 | 写执念和行动；术语融入铺垫，让外行也能懂 |
| 程序员 | 重现问题、命名、日志、评审、交接 | 不只堆 Bug、AI、加班黑话，不天天“修一处坏十处” |
| 打工人／设计师 | 会议发言、文件名、排期、取外卖、甲方沟通 | 具体矛盾代替抱怨，不编造真实企业内幕 |
| 健身／跑步／骑行 | 数次数、约伴、休息、路线、装备 | 写习惯，不靠身材羞辱，不把段子当运动指导 |
| 摄影／数码／机械键盘 | 器材、拍照站位、文件整理、借设备、敲字声 | 产品当前价格、参数先核验，人物选择承担笑点 |
| 养宠／养花 | 作息、玩具、浇水、家庭分工 | 虚构可辨，不捏造宠物医学事实 |
| 校园／考研／桌游／追剧 | 自习、约时间、复习计划、解释规则、避剧透 | 不冒称真人经历，不无故泄露关键剧情 |
| 苏联政治笑话 | 宣传与生活落差、指标、排队、官僚推诿 | 笑话不当历史证据；流传出处与原作者分开，未核验不称经典 |
| 英式官僚讽刺 | 模糊承诺、程序与结果、责任转移、话语博弈 | 《是，大臣》《是，首相》属于英国剧集，按表演形式参考处理来源与新创作 |

## 每日编排

所有来源和外部 CLI 任务均明确排除调侃中国及中国领导人的政治笑话，含谐音、代称和可识别影射。原始抓取只产生未审候选，导入器不具备语义审查能力；Agent 必须筛查后才能选稿，不能直接从 JSON 随机抽取发布。遇到排除内容只记录简短原因，不向用户复述原段子。

默认 6 个圈层短笑话 + 2 段相声 + 1 则苏联政治笑话 + 1 段英式官僚讽刺，共 10 个。圈层与形式可交叉：相声可以讲钓鱼，英式讽刺也可以写虚构办公室。混合模式尽量覆盖至少 5 个题材，各普通圈层通常 1—2 个；用户指定单圈、比例、排除项时覆盖默认，不强塞其他圈子。

长稿另写 1 篇，默认围绕一个圈层推进，可有因果相连的跨圈对照，不复读当天短篇结尾。素材不足时定向搜索或独立构思，不能只把旧段子的人名换成游戏角色。不能用多个标签把同一节目重复计数。

必要编辑字段为 `id`、`topic`、`format`（short_joke／xiangsheng／satirical_dialogue）、`dominant_structure`、来源类别与链接。长稿单列 `kind: standup`，不参与短篇数量与机制配额。题材建议不自动写成用户永久偏好；已有禁区和当前请求优先。
