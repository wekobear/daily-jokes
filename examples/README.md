每个案例包含故事输入、来源和实际图片；案例目录中的 Markdown 即可作为图文阅读稿。故事经过中文改编，图片为 AI 生成，用户可据自己的用途再次核实素材使用条件。

这些样例用于复刻制作步骤，不保证重新调用模型能逐帧重现。H3 视频保留服务商的 AI 生成标识元数据；其中的来源标记或公开签名不是 API Key。私有任务状态、鉴权凭据、签名下载链接和聊天记录不随案例公开。
