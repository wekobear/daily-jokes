# 每日五个笑话 · daily-five-jokes

一个可分享的 Agent Skill：首次只补齐偏好，日常生成五个主导喜剧结构不同的短笑话，结合联网精选与原创；定时生成与发送按宿主的真实能力接入。

## 使用

从本仓库的 Releases 下载 `daily-five-jokes.zip`，解压后将完整的 `daily-five-jokes/` 文件夹交给支持 Agent Skills 的宿主安装。保留相对目录，不要只复制入口文件。

对于支持用户级 Skill 目录的 Codex 环境，也可将整个目录放入该环境配置的 `skills` 目录，再在新的会话中确认技能已被发现。仓库根目录本身就是 Skill 目录；从源码归档安装时可将其目录名改为 `daily-five-jokes`。

支持显式 Skill 调用的宿主可使用 `$daily-five-jokes`；其他 AI 可以读取 `SKILL.md`，并按其中路由读取参考文件。复制指令不会为宿主增加搜索、存储或推送工具。

所有请求示例均为虚构、去标识化数据：

```text
$daily-five-jokes 帮我设置偏好，先不生成。

$daily-five-jokes 别问，直接来一组。

$daily-five-jokes 来五个生活和科技笑话，温和，避开疾病，不加入自嘲。

$daily-five-jokes 我带了空购物袋去买菜，这件事仅本次可温和调侃，不保存。现在来一组。
```

若用户只要求设置，Skill 不附赠笑话。正常生成只输出编号 1—5 的笑话，网络素材保留对应的必要来源引用。缺少搜索能力时会说明实际降级情况。

## 核心规则

- 区分题材、呈现形式和主导喜剧结构；本组五种不同机制是硬要求，七天轮换是软目标。
- 查重比较目标、行动、误导预期和揭底关系，区分核心包袱复用、同一母题过密与仅题材相同。
- 自嘲默认关闭，只使用明确授权的具体经历；不自动翻阅私事。一次性使用、未来使用、保存和对外发送分别判断。
- 定时需要真实执行与送达工具、明确时区及用户订阅授权。保存发送时间不代表任务已经创建。
- 只把实际展示或发送的内容记录为已送达，按授权保留最小七天查重信息；不把草稿或失败操作记为成功。
- 每位用户的数据与设置独立，Skill 包不包含任何人的真实偏好、经历或历史记录。

## 验证范围

已检查 YAML frontmatter、相对引用、18 个结构 ID、31 项验收规格的必要字段，以及封装文件一致性。完成四个流程场景和五项语义判断的独立模拟；首次设置漏问自嘲选择的问题已修正并复测。

`tests/acceptance.md` 是验收规格，不能将其等同于 31 项全部运行通过。真实联网、定时推送、持久化和跨日联调需在安装宿主中验证；笑话是否好笑仍需要人工和用户反馈判断。
