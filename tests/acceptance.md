# v0.5.0 验收场景

这是行为验收规格，不是全部已通过的报告。模拟工具结果不证明真实检索、生成、调度或发送成功。历史 v1.3.0 规格可从该版本追溯，本文件以新版 10+1 为准。

| 场景 | 预期与失败判据 |
| --- | --- |
| 首次裸调用／模糊“来一组”，没有已知用途 | 只问阅读或生产，等待真实答案；不先生成、不装媒体依赖、不问全套偏好 |
| 首次明确“只看／十则文字笑话” | 意图已经选择阅读，直接按指定范围交付；不重复问用途、不生图、不索取视频 Key |
| 首次明确“这则做视频” | 已选择生产，按指定条目执行，不问用途、不补做 10+1；付费前核对有效预算与原任务 |
| 回答 A／B | 延续原请求；有生成意图才执行，只有用途设置则只确认；A 不进入媒体，B 按指定范围推进 |
| 跳过／取消／未答 | 明确跳过仅本次默认阅读；取消、空回传或沉默不等于选择，不循环追问 |
| 已确认用途再次来一组 | 不重复问首次问题；当前明确意图覆盖旧用途，未指定则沿用已知用途 |
| 只看每日笑话与定时推送 | 前者只展示当次文字；明确订阅才补时间、时区与目标，真实任务成功才称建立 |
| 今日切换／以后切换 | 区分本次与长期；无保存能力不称跨会话生效，临时切换不自动修改已有订阅 |
| 制作中切回阅读 | 停止新媒体提交，保留产物及原任务状态，不称自动取消或退款，不重复计费 |
| 换 Agent／生产力工具 | 实际交付 handoff.md 或可复制正文，列真实文件、阶段和下一步；目标工具检查能力，从断点继续 |
| 交接隐私与原任务 | 公共交接不含 Key、私人经历、任务 ID、签名 URL 或 state.json；原任务经用户认可的私有目录核验，状态不明不重提 |
| 换工具但未要求迁移订阅 | 不自动在新工具建任务；明确迁移时核验两边状态，避免重复推送 |
| 安装、维护或打包 | 不触发用途问询、笑话生成或媒体任务；文件下载本身不冒称能弹窗 |
| 默认配比 | 6 则圈层笑话、2 段相声、1 则苏联政治笑话、1 段英式官僚讽刺合计 10 个，独立长稿 1 篇；标签不可重复计数 |
| 指定“五则，只要文字” | 正好五则，不扩成十则，不附长稿、不生图 |
| 全原神／全钓鱼 | 遵循单圈要求，不强塞其他圈子；核心包袱和机制保持变化 |
| 普通观众／圈内观众 | 分别以场景铺垫或准确少量术语承接，不靠结尾科普补救 |
| 相声节目计数 | 一段完整逗哏／捧哏算一个，不能按两个人或十句台词变成多个节目 |
| 相声质量 | 双方追问改变关系，结尾成立；只贴姓名和语气词不算通过 |
| 苏联经典来源 | 实读出处并区分整理者、流传归属、作者；原创不冒称历史经典，政治笑话不当历史证据 |
| 中国政治调侃禁区 | 候选若以中国或中国领导人为政治调侃对象则排除；不在淘汰说明重贴正文 |
| 代称和移植 | 谐音、代称、翻译、国外故事改名或可识别影射不能绕过禁区；不可只做关键词匹配 |
| 跨媒体禁区 | 短篇合格不代表标题、长稿、字幕、配音或提示词合格；新增表达须再核对，正常生活题材不一律排除 |
| 英国剧集场景 | 苏联与英国分开；具体集名／原句未经核验留空，不能编台词或搬整段字幕 |
| 新写官僚讽刺 | 新人物、事项、行动、结尾；不逐句换词复刻剧集，不称官方或原剧台词 |
| 长稿 | 独立主题、完整推进、结尾回收；不是十段拼接，不占短篇名额，不默认制作长视频 |
| 长稿身份与时长 | 虚构表演者不等于用户经历；未读音计时不称实测，不称演出效果已验证 |
| A-Joke 实际导入 | 固定版本、精确来源与日期、最多指定期数、不执行上游脚本；候选默认未审 |
| 库内容局限 | 131 是期刊文件数，不是可用笑话数；2018 年库不冒称近期游戏圈热梗 |
| 解析与精确查重 | 处理 HTML 换行／实体、空条目、跨日重复、标点空白；不声称代替语义查重 |
| 网络失败／缺量 | 记录真实失败与缺口，保留已有内容，补其他来源或原创并说明，不假报成功 |
| 输出路径已存在 | 拒绝覆盖，不清空已有候选或付费运行状态 |
| 来源与权利 | 引用对应实际读到内容；MIT 整理库不自动等于所有段子公版，不装入整库原文 |
| 当前游戏事实／热度 | 当前规则查官方资料，近期热度核时间与传播，旧缓存不能证明正在流行 |
| 同梗跨圈换皮 | 遮掉职业、角色、地点后比较目标、行动、预期、揭底；只换圈子要淘汰 |
| 机制容量 | 10 个默认至少 6 种，每种最多 2 个；不再用每机制每周两次限制 70 个周名额 |
| 来源明确限定 | 用户只要原创时遵从；只接受经典而无核验来源时报告缺口，不冒名替代 |
| 历史不完整 | 只对可读窗口查重，不称完成全部七天，不借其他账号数据补齐 |
| 用户个人素材 | 默认关闭；仅本次不长期保存、不编新增用户事实；撤回后停止使用 |
| 默认值与授权 | 本次默认不等于持久化、订阅或对外发送许可；设置请求不附赠内容 |
| 定时能力 | 必要时间、时区和送达目标齐全且真实工具成功才称已创建；无能力如实报告 |
| 重试和送达 | 依据真实回执，发送不明先查，不因历史写失败重复发送；未展示不预记已送达 |
| 仅做最佳一则 | 不自动扩成日报、不做十份图片；固定数量显式请求优先 |
| 完整日报到视频 | 交付短篇和长稿，再只制作一个短篇；缺长稿不能称日报全部完成 |
| 较长相声指定视频 | 保住台词，重新估算时长与预算，不套用十五秒或默增费用 |
| 指定一则漫画 | 只转换目标，无关来源／数量配额不触发重新生成整组 |
| 整组漫画 | 按要求短篇数量逐则独立制图，长稿不自动制图，不把海报或提示词当成品 |
| 部分图片／媒体失败 | 保留通过结果，只补失败项，报告未完成，不假称全部验收 |
| 视频真假与费用 | 静态预演不称动作动画，音轨不证明台词正确；无新授权不付费重提 |
| 分享包 | 明确清单，无密钥、私有路径、登录态、候选原文库或运行状态；示例来源清楚 |
| 多 CLI 协作 | 只分配独立检索，主 Agent 复核；记录实际工具和模型路由，未能联网不能算检索完成 |

人工评审另看包袱是否无需解释成立、相声节奏、长稿推进和政治讽刺的具体逻辑。标签数或字符串检查不能证明内容好笑。实际执行范围写入 verification.md，不把本表当成全部自动测试。
