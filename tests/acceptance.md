# 验收场景

本文件是可复用验收规格，不是执行通过记录。所有经历、人物、标识与工具回执均为虚构测试数据；模拟工具名称只描述能力，不代表宿主存在同名 API。运行时另存测试报告，并注明实际环境、观察结果、证据和未测项。

## 如何执行

把 Skill 和单个场景的输入、环境前提交给执行者；保留实际回复、实际／模拟工具操作与状态变化，再依据预期行为和失败判据评审。对没有提供的工具和数据按不可用处理。模拟场景不得接触真实用户数据、创建真实任务或向他人发送消息。

- 格式检查可验证 frontmatter、路径、引用可达、包内不含真实用户状态及成品是否五条。
- 行为试跑可观察路由、授权、降级、状态转移及重复判断；模拟通过不等于真实搜索、调度、推送和持久化联调通过。
- 幽默质量、自然度和结构分类需人工判断。不能用标签数、词频或字符串断言证明“好笑”或“没有换皮”。

## 人工出稿评审

选正常生成、降级、个人经历三类各一组，检查每条铺垫是否必要、包袱能否无解释成立、语气是否自然、结尾是否及时；再遮掉名称和题材，比较五条和最近可读记录是否仍有相同揭底。记录具体哪条成立／不成立以及原因，不把主观评分写作程序证明。

历史反馈用“用户明确评价”和“评审推断”分栏。没被批评不等于用户喜欢；曾用过的名著、行业或具体偏好不应写成所有用户的默认项。
